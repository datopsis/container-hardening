# AU-4 Audit Log Storage Capacity

| | |
| --- | --- |
| Origination | `host-inherited` |
| High baseline | Selected |
| Criteria | [IMG-19](../standard/criteria.md#img-19-logs-to-standard-streams-without-secrets) |
| Handoff | [PLT-09](../standard/platform.md#plt-09-logs-are-collected-centrally) |
| Catalogue | NIST SP 800-53 Rev 5, 5.2.0, with SP 800-53A procedures |

The image writes its records to standard streams and keeps none. Storing, protecting, retaining, and processing them is the platform's log store (PLT-09).

## Control

- Allocate audit log storage capacity to accommodate [*Assignment: audit log retention requirements*].

## Assessment objective

Determine if:

- **AU-04** audit log storage capacity is allocated to accommodate [*Assignment: audit log retention requirements*].

## Assessment methods

### Examine

- Audit and accountability policy
- procedures addressing audit storage capacity
- system security plan
- privacy plan
- system design documentation
- system configuration settings and associated documentation
- audit record storage requirements
- audit record storage capability for system components
- system audit records
- other relevant documents or records

### Interview

- Organizational personnel with audit and accountability responsibilities
- organizational personnel with information security and privacy responsibilities
- system/network administrators
- system developers

### Test

- Audit record storage capacity and related configuration settings
