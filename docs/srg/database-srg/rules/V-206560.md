# SRG-APP-000177-DB-000069

**The DBMS must map the Public Key Infrastructure (PKI)-authenticated identity to an associated user account.**

## Discussion

The DoW standard for authentication is DoW-approved PKI certificates. Once a PKI certificate has been validated, it must be mapped to a DBMS user account for the authenticated identity to be meaningful to the DBMS and useful for authorization decisions.

## Check

Review DBMS configuration to verify DBMS user accounts are being mapped directly to unique identifying information within the validated PKI certificate.

If user accounts are not being mapped to authenticated identities, this is a finding.

## Fix

Configure the DBMS to map the authenticated identity directly to the DBMS user account.
