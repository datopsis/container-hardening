# AU-6(5) Integrated Analysis of Audit Records

| | |
| --- | --- |
| Origination | `organization-inherited` |
| High baseline | Selected |
| Criteria | [IMG-19](../standard/criteria.md#img-19-logs-to-standard-streams-without-secrets) |
| Catalogue | NIST SP 800-53 Rev 5, 5.2.0, with SP 800-53A procedures |

Reviewing and analyzing audit records is done by the organization's people, using the platform's log store.

## Control

- Integrate analysis of audit records with analysis of [*Assignment: au-06.05_odp.01*] to further enhance the ability to identify inappropriate or unusual activity.

## Assessment objective

Determine if:

- **AU-06(05)** analysis of audit records is integrated with analysis of [*Assignment: au-06.05_odp.01*] to further enhance the ability to identify inappropriate or unusual activity.

## Assessment methods

### Examine

- Audit and accountability policy
- system security plan
- privacy plan
- procedures addressing audit review, analysis, and reporting
- system design documentation
- system configuration settings and associated documentation
- integrated analysis of audit records, vulnerability scanning information, performance data, network monitoring information, and associated documentation
- other relevant documents or records

### Interview

- Organizational personnel with audit review, analysis, and reporting responsibilities
- organizational personnel with information security and privacy responsibilities

### Test

- Mechanisms implementing the capability to integrate analysis of audit records with analysis of data/information sources
