# SRG-APP-000705-AS-000110

**The application server must disable accounts when the accounts are no longer associated to a user.**

## Discussion

Disabling expired, inactive, or otherwise anomalous accounts supports the concepts of least privilege and least functionality, which reduce the attack surface of the system.

## Check

Verify the application server disables accounts when the accounts are no longer associated to a user.

If the application server does not disable accounts when the accounts are no longer associated to a user, this is a finding.

## Fix

Configure the application server to disable accounts when the accounts are no longer associated to a user.
