Memory protection, non-executable memory and address space randomization, is provided by the host kernel. It is reached through the platform's resource rule, which does not describe it.

### Examine

- system security plan
- other relevant documents or records

### Interview

- Organizational personnel responsible for memory protection
- organizational personnel with information security responsibilities
- system/network administrators
- system developer

### Test

- Automated mechanisms supporting and/or implementing safeguards to protect the system memory from unauthorized code execution
