# AC-11 Device Lock

Concerns a user's device or its radio, keyboard, or display. A container image has none, and runs on a server whose physical interfaces are the facility's.

## Control

- **a.** Prevent further access to the system by [*Assignment: ac-11_odp.01*] ; and
- **b.** Retain the device lock until the user reestablishes access using established identification and authentication procedures.
