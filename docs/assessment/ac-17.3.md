# AC-17(3) Managed Access Control Points

| | |

Remote access to the system is administration of the platform (PLT-13). The image offers no remote access of its own (IMG-27).

## Control

- Route remote accesses through authorized and managed network access control points.

## Assessment objective

Determine if:

- **AC-17(03)** remote accesses are routed through authorized and managed network access control points.

## Assessment methods

### Examine

- Access control policy
- procedures addressing remote access to the system
- system design documentation
- list of all managed network access control points
- system configuration settings and associated documentation
- system audit records
- system security plan
- other relevant documents or records

### Interview

- System/network administrators
- organizational personnel with information security responsibilities

### Test

- Mechanisms routing all remote accesses through managed network access control points
